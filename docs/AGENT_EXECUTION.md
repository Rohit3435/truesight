# Agent execution

`orchestrateInvestigation` runs independent evidence agents concurrently and records each result as completed, skipped, or failed. `canRun` methods gate execution on evidence kind and, for external model calls, explicit user consent and configured credentials. `Promise.allSettled` preserves successful work when a different agent fails. Findings pass through evidence verification, which removes unsupported evidence references and keeps claims linked to evidence IDs.

Current deterministic agents describe supplied profile fields, literal caption hashtags, supplied professional-material categories, and literal external links. URL findings explicitly say that destination reputation was not checked. The username OSINT status is visible but skipped until an approved provider is configured; no external sites are probed. The toxicity classifier and Gemini/Groq/Ollama evidence-observation and image agents are adapters behind provider interfaces; they run only when configured and consented. Missing inputs or keys are explicit skipped states. No agent assigns identity, criminality, trustworthiness, health, or a fabricated risk score.

The existing orchestrator intentionally remains a small typed workflow instead of adding LangGraph: there are no durable checkpoints or background worker to support graph resumability. URL reputation adapters exist separately but are not yet connected to report generation. The report includes visible orchestration, evidence-verification, and report-generation workflow statuses; report assembly remains synchronous in the API route.
